# Basin Bench

CS 533 Experimental Methods in Computer Science, Fall 2026, UNM. Group project.

Question: does a hybrid GR4J + XGBoost model predict daily streamflow better than
GR4J alone or XGBoost alone on the CAMELS benchmark of US river basins?

Layout

- handouts/      course milestone handouts
- submissions/   what we handed in, dated
- notes/         reading notes and decisions
- notebooks/     exploration and pilot analysis
- data/          CAMELS downloads (not tracked in git; see notes/data.md once written)
- slides/        the running presentation, updated at every milestone
